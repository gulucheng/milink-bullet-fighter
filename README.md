# MiLink 弹幕战机 — Roguelike

肉鸽弹幕射击游戏，支持键盘/鼠标/手机控制器，包含星系探索、部件收集、战机进化、商店系统、科技树永久升级。

## 功能

- **肉鸽玩法** — 每局随机升级卡牌、随机商店商品、部件掉落，策略选择打造专属战机
- **星系选择** — 5 个星系（土星带/火焰/冰霜/雷电/暗影），不同掉落池和难度
- **部件收集** — 武器/引擎/装甲/特殊 4 类部件，击败敌人掉落
- **战机进化** — 火力/生存/速度/特殊 4 条进化路线，每条 4 级，部件驱动
- **商店系统** — 金币购买技能、血量、护盾、大招（Q 键释放）
- **科技树** — 永久加成：攻击力/生命/移速/能量回复/金币获取/部件掉率
- **战机型号** — 5 种机型（默认/突击/重装/侦察/毁灭），不同属性和解锁条件
- **Boss 战** — 每 10 波出现 Boss，3 种攻击模式（散射/召唤/激光）
- **多人协作** — WebSocket 实时通信，手机扫码当控制器
- **键盘控制** — WASD/方向键 8 方向移动，J/K/L/Q 快捷键
- **成就系统** — 8 个成就，本地持久化
- **排行榜** — WebSocket 实时同步

## 快速开始

```bash
# 安装依赖
npm install

# 启动服务器
npm start
```

打开浏览器访问 `http://localhost:3000`

手机扫码连接控制器：点击底部 📱 扫码按钮，弹出二维码后扫描

## 操作方式

### 键盘
| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动战机 |
| J | 发射子弹（按住持续射击）|
| K | 发射导弹（-10 能量）|
| L | 电磁脉冲（-50 能量，冷却 10s）|
| Q | 释放大招（需在商店购买装备）|
| 空格 | 闪避冲刺 |
| Shift | 子弹时间 |
| 1 / 2 | 切换武器模式（散射/集中）|
| P / ESC | 暂停 |

### 面板键盘选择
| 场景 | 按键 | 功能 |
|------|------|------|
| 升级卡片 | 1 / 2 / 3 | 选择升级卡牌 |
| 商店 | 1-6 | 购买商品 |
| 商店 | R | 刷新商品（10 金币）|
| 进化 | 1 / 2 / 3 | 选择进化路线 |
| 进化 | N | 跳过进化 |

### 鼠标
鼠标移动控制战机 X 轴位置（无键盘输入时自动启用）

## 进化路线

收集足够部件后在波次间选择进化：

- **火力路线** (🔫 武器部件) — 强化弹药 → 三连射 → 激光弹幕 → 轨道打击
- **生存路线** (🛡 装甲部件) — 装甲板 → 自动护盾 → 伤害反射 → 不死凤凰
- **速度路线** (⚙ 引擎部件) — 涡轮推进 → 闪避残影 → 时间扭曲 → 相位移动
- **特殊路线** (💎 特殊部件) — 磁力场 → 连锁闪电 → 量子分裂 → 暗物质

## 战机型号

| 机型 | 特性 | 解锁条件 |
|------|------|---------|
| 🚀 默认型 | 平衡 | 默认 |
| ⚡ 突击型 | +30%射速 -20%HP | 总局数≥5 |
| 🛡 重装型 | +50%HP +20%伤害 -20%移速 | 总局数≥10 |
| 🔭 侦察型 | +40%移速 -30%HP 大拾取范围 | 最佳波次≥10 |
| 💀 毁灭型 | +40%伤害 -25%移速 | 最佳波次≥15 |

## 科技树

每局结束获得科技点（1 点/100 分数），永久升级：

| 项目 | 效果/级 | 最大等级 |
|------|---------|---------|
| 攻击力 | +5%伤害 | 5 级 |
| 生命值 | +1 最大HP | 3 级 |
| 移速 | +5%移速 | 3 级 |
| 能量回复 | +10%回复 | 3 级 |
| 金币获取 | +10%金币 | 3 级 |
| 部件掉率 | +5%掉率 | 3 级 |

## 波次间流程

```
Wave Complete
  → 部件掉落结算
  → 进化选择（部件足够时）
  → 商店购买（金币消费）
  → 升级卡牌选择（肉鸽随机）
  → 下一波开始
```

## 技术栈

- **前端** — HTML5 Canvas, 原生 JavaScript
- **后端** — Express.js, Socket.io
- **通信** — WebSocket 实时双向通信
- **存储** — localStorage 持久化（科技树/成就/历史数据）
